IMAGE PIPELINE

이미지 생성 및 분석 API

프롬프트로 이미지를 만들고, 이미지 내용을 분석해 작품 등록 문구를 생성합니다.

1. Prompt사용자가 원하는 이미지 설명을 입력합니다.
2. Generategpt-image-1-mini로 PNG 이미지를 생성합니다.
3. Upload생성 이미지를 AWS S3에 업로드하고 presigned URL을 만듭니다.
4. Analyze이미지 URL 또는 파일을 비전 모델로 분석합니다.
5. Return제목, 설명, 이미지 URL, 파일 정보를 응답합니다.

처리 흐름

1

2
Speech To Textgpt-4o-mini-transcribe로 녹취록을 생성합니다.
3
LLM Summary회의 개요, 가격 조건, 물류, 결제, 합의사항, 액션 아이템으로 구조화합니다.
4

경매 RAG 분석

문서 인덱싱, 비전 분석, 하이브리드 검색을 결합해 경매 투자 분석 보고서를 생성합니다.

RAG 처리 단계

1
문서 인덱싱POST /api/auction/rag/index로 PDF 리포트를 지식베이스로 처리합니다.
2
이미지/작품 분석경매 작품의 제목, 설명, 태그, 가격, 반응 지표를 함께 분석합니다.
3
Hybrid QueryRAGAnything + LightRAG가 문서 근거와 입력값을 결합합니다.
4
투자 보고서가격 매력도, 예상 낙찰가, ROI 시나리오, 입찰 추천을 반환합니다.
